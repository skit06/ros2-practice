# 🤖 ROS 2 核心记忆练习站 (ROS 2 Flashcards & Code Practice)

基于日常学习积累的 12 份 ROS 2 核心笔记提炼打造的交互式默写与记忆练习站。  
涵盖 **工作空间与构建**、**Python 节点**、**C++ 节点**、**话题通信 Pub/Sub**、**CLI 反查命令**、**自定义接口 .msg**、**服务通信 Client/Server**、**参数系统与 Launch 启动**、**海龟控制与运动学**、**Qt 上位机界面** 共 10 大模块、62 道高频实操考题。

---

## 🌟 特性亮点

- ⚡ **开箱即用**：零构建步骤、纯静态运行，手机与电脑浏览器秒开。
- 📱 **移动端全适配**：支持手机端快捷按键栏（`Tab`、`_`、`::`、`->`、`ros2` 等常见代码符号一键输入），通勤地铁随时背题。
- 👁 **防偷看遮罩**：支持模糊防偷看模式，先默写再对照，鼠标悬停或点击即可局部刮开查看。
- 🔍 **逐行 Diff 对照**：智能比对你的默写内容与标准代码，红绿高亮显示缺失行、多余行与不符行。
- 💾 **本地离线记忆**：作答进度（已掌握 / 需复习）自动持久化至浏览器本地缓存，更新题库不丢进度。

## 💻 本地运行

双击进入 `ros2-practice` 目录运行 `start.bat`，即可在本地浏览器启动。也可以直接双击 `index.html` 离线体验。
