# ROS 2 记忆练习

纯本地、无依赖的中文练习网页。练习卡片来自当前工作区的 ROS 2 `.docx` 笔记；答题进度存在浏览器 `localStorage`。

## 启动

需要 Node.js 18 或更新版本。在此目录打开终端并运行：

```powershell
node server.js
```

然后访问 http://127.0.0.1:4173 。按 `Ctrl+C` 停止本地网页服务。无需 `npm install`，无需网络或外部数据库。

也可以直接用浏览器打开 `index.html`；如果选择这个方式，剪贴板复制功能可能受浏览器本地文件权限限制。

## 包含的练习

- 功能包创建、colcon 构建、环境激活与运行
- ros2 topic list/echo/info、rqt_graph
- Python 与 C++ 节点标准骨架、CMake 注册
- String 话题发布者/订阅者与回调
- Python 面向对象节点模板

卡片按学习路径固定排序：Python 节点基础 → 面向对象模板 → 话题发布订阅 → 话题排查命令 → Python 功能包流程 → C++ 节点与功能包流程。可按模块筛选或搜索；“上一题 / 下一题”始终沿当前顺序导航。答案支持展开、复制和逐行对照；练习后可标记“已掌握”或“需要复习”。
